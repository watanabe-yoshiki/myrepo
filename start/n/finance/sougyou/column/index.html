創業コラム

創業コラムでは、日本公庫が運営する創業をお考えの方、
創業後間もない方向けのメールマガジン（起業家応援マガジン）で配信した
専門家のコラムを掲載しています。

創業へのステップ

  • 第1回 ビジネスアイデアやコンセプトを整理しよう
  • 第2回 ターゲットの絞り込みを行い集客プランを具体化しよう
  • 第3回 商圏分析と競合調査をしよう
  • 第4回 売上予測と損益分岐点分析をしよう
  • 第5回 「ヒト」や「モノ」への投資について考えよう
  • 第6回 資金調達の準備をしよう

Webでの新規集客とリピート作り

  • 第1回 創業期の顧客獲得とWeb集客
  • 第2回 Webを活用した新規顧客獲得術（検索に対応する集客方法）
  • 第3回 Webを活用した新規顧客獲得術（SNSを活用する集客方法）
  • 第4回 お客様目線の情報発信
  • 第5回 Webを活用してリピーターを作るためには

メール配信サービス

創業者向け 起業家応援マガジン(登録無料)

創業をお考えの方、創業後間もない方に、経営に役立つ情報をご提供します（不定期配信）。
「起業家応援マガジン」の情報配信サービスをご利用いただく場合、日本公庫がインターネットで提供する無料の会員専用サイト「日本公庫ダイレクト」にご登録いただく必要がございます。
会員情報をご登録の際に、メールマガジン登録の「起業家応援マガジン」にチェックを入れてください。

  • 経営ノウハウ
  • 創業企業の事例

  • 融資制度
