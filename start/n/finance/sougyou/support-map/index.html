支援拠点Map

国民生活事業の創業・スタートアップ支援体制

  • 創業サポートデスク（支店）152ヶ所

  • ビジネスサポートプラザ3ヶ所

    じっくりとしたご相談を希望される創業をお考えの方などを対象に、予約制の相談を実施しています。

  • 創業支援センター14ヶ所

    各地域の創業支援機関などと連携し、創業前、創業後のさまざまなステージのお客さま向けに各種セミナーを開催するなど、お客さまヘタイムリーな支援を行っています。

  • スタートアップサポートプラザ4ヶ所

    スタートアップ支援機関と連携し、スタートアップに対する各種セミナーの開催、予約制の相談を実施しています。
