創業サポートデスク

日本公庫　国民生活事業では、平成24年4月に全国152支店に「創業サポートデスク」を設置しております。
専任の担当者が、創業計画書の立て方や融資申し込みの流れ、融資制度等について丁寧にお応えします。
ご希望の方は、直接最寄りの支店(店舗一覧よりご確認ください。)にお電話いただくか、「創業相談予約」ページからご予約ください。
